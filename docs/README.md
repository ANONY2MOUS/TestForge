## ✅ What TestForge Does

TestForge is a dual-layer testing platform that:

1. **E2E Tests (Playwright)** — Tests real browser interactions on GitHub.com
2. **API Tests (pytest)** — Tests REST endpoints on api.github.com
3. **Unified Reporting** — Generates a beautiful HTML dashboard combining both
